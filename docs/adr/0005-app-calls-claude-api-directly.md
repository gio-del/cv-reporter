# App calls the Claude API directly; tailor-cv skill kept in parallel

Generation (Selection, Rewrite, Cover Letter drafting) now runs as app backend logic calling the Claude API directly, rather than the app shelling out to Claude Code to run the tailor-cv skill headlessly. The skill's Text Review/Visual Review checkpoints assume a live conversational back-and-forth, which doesn't map cleanly onto a non-interactive invocation — the app needs to render those checkpoints as FE UI (a diff view, a PDF preview) instead. This means the pipeline logic now exists in two places: the skill (`.claude/skills/tailor-cv/SKILL.md`) and the app. We're deliberately keeping both — the skill remains for quick conversational/CLI use without opening the app — accepting the risk that they drift out of sync over time rather than collapsing to one path.
