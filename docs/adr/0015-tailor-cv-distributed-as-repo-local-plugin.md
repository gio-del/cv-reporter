# tailor-cv distributed as a repo-local Claude Code plugin, not .claude/skills/

The `tailor-cv` skill now lives at `plugins/cv-reporter-skills/skills/tailor-cv/SKILL.md`, packaged as a plugin (`plugins/cv-reporter-skills/`) served by a repo-local marketplace (`.claude-plugin/marketplace.json`), instead of the more obvious `.claude/skills/tailor-cv/`. This repo's `.claude/` directory is entirely gitignored, because the author's general-purpose personal skills (`develop`, `tdd`, `domain-modeling`, `grilling`, etc.) are synced into it from an external personal skills repo via `skills-lock.json` and were never meant to be versioned here — but that also silently gitignored `tailor-cv`, the one skill this repo actually owns, so edits to it were invisible to git and uncommittable. Rather than carve out a `.gitignore` exception inside `.claude/` (fragile, and it would blur the line between synced personal skills and this repo's own), `tailor-cv` was moved to a plugin the repo tracks directly, leaving `.claude/` untouched and fully gitignored as before. The trade-off: the skill is now invoked as `/cv-reporter-skills:tailor-cv` instead of `/tailor-cv`, and picking it up automatically in a fresh checkout needs `.claude/settings.json`'s `extraKnownMarketplaces`/`enabledPlugins` set (or a manual `/plugin marketplace add .`) rather than nothing at all.
