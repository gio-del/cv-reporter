# Go backend, React + TypeScript + Vite frontend

ADR-0004 decided on a standalone local web app (backend + FE, docker-compose, localhost-only) but left the concrete languages open. Backend is Go: a single static binary keeps the docker-compose story simple for a single-user localhost app, and its standard library covers HTTP serving without much dependency surface. This is a deliberate split from the FE's language rather than a shared Node/TS stack — accepted because the backend here is a thin, mostly-CRUD file-reading/writing API, not somewhere Go's lack of a shared type system with the FE causes real pain. FE is React + TypeScript + Vite, matching prior React experience and giving a fast local dev loop. Tests are written with Go's built-in `testing` package, run as HTTP integration tests against the live backend per the PRD's seam decision (request in, file/response out).
