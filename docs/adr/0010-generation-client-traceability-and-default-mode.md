# Generation validates Client output for traceability; Default Mode never calls Claude

Selection+Rewrite output from the `generation.Client` (ADR-0005) is checked against Master Data before being trusted: every returned Entry id, bullet index, and reported source-bullet text must match what's actually on disk, or the request fails with `ErrInvalidSelection` (HTTP 502) rather than reaching Text Review. Rewrite is deliberately exempt from this check — it's expected to reword source text — so this backstop only catches a Client response that isn't traceable to Master Data at all (wrong id, wrong index, fabricated "source"), not subtler prose drift; ADR-0002's two-stage HITL review remains the defense against that. Default Mode (no Job Description) is a separate, deterministic code path that never calls the Client: CONTEXT.md already specifies Rewrite is skipped and Selection falls back to a fixed rule, so there's no reason to spend an API call or expose Default Mode to LLM non-determinism when the outcome should always include every Entry unmodified.
