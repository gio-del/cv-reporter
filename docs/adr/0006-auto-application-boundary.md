# Auto-application limited to legal, ToS-compliant mechanisms only

The FE prepares everything for an Application (Tailored CV, Cover Letter, Contact, an email draft) but automated submission is only attempted where it carries no legal or ToS risk: a prefilled `mailto:` draft the user sends themselves, and documented public ATS submission/job-board APIs (Greenhouse, Lever, Ashby) used as intended. Explicitly out of scope: LinkedIn Easy Apply automation and generic browser-automation form-filling against arbitrary company portals — both risk violating platform ToS (LinkedIn's prohibits automated/scripted interaction) and, for Easy Apply, risk account suspension. Where no compliant automatic path exists, the FE guides the user through a manual step instead of attempting one.
